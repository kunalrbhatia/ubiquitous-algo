### Description

Fixes case-sensitive date parsing issues and implements file-based lock checking to prevent concurrent cron execution blocks.

### Changes

- Added a unified `parseExpiryDate` function in `src/instruments/dateUtils.ts` to convert uppercase month abbreviations (e.g., `AUG`, `SEP`) to camelcase for robust parsing.
- Refactored `src/instruments/instrumentManager.ts`, `src/strategy/strategyManager.ts`, and `src/scheduler/cronScheduler.ts` to use the unified date parsing.
- Implemented `acquireLock` process locking mechanism in `src/index.ts` using `trading-tick.lock` and `process.kill(pid, 0)` checks.
- Added documentation for `trading-tick.lock` to the Controls section in `README.md`.
- Added unit tests in `__tests__/dateUtils.test.ts` and updated mock in `__tests__/strategyManager.test.ts`.

### Verification

- Run `pnpm test` successfully passing 133 tests with 100% code coverage.
